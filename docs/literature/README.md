# Literature

This folder holds the literature review and the full-text paper extractions
for the project. Both are added by the author.

## Source tags

Each source in the review carries one tag:

| Tag | Meaning |
|---|---|
| (R) | read in full |
| (A) | abstract only |
| (N) | not opened |

## Rules

- A tag is never upgraded without reading the text.
- When a number is needed, it is taken from the paper text, not from memory,
  and cited with the paper and the table or figure it comes from.
- This folder is consulted when an analysis is designed.
